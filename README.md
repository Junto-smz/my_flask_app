# Jリーグアウェイ遠征家計簿

##　概要
Jリーグのアウェイ観戦・遠征にかかった費用を記録、管理するためのWebアプリです。
遠征ごとに交通費、宿泊費、チケット代、食費、グッズ代などの支出を登録し、遠征単位・カテゴリ単位・月単位で支出を振り返ることができます。

## 作成背景
Jリーグ観戦では、チケット代だけでなく、交通費、宿泊費、食費、グッズ代など複数の費用が発生します。
そのため、遠征毎にどれくらい費用が掛かったのかを記録し、あとから振り返ることが出来るアプリを作成しました。
このアプリはFlask, SQLite, HTML/CSS, Git/GitHubの学習成果物として作成しています。

## 主な機能
- 支出の登録、一覧表示、編集、削除
- 遠征の登録、一覧表示、編集、削除
- 支出と遠征の紐づけ
- 遠征毎の支出一覧表示
- 遠征毎の合計金額表示
- 遠征毎ののカテゴリ別合計表示
- 遠征一覧での合計金額表示
- 全支出の合計金額表示
- カテゴリ別合計表示
- 月別合計表示
- カテゴリ・月による支出絞り込み
- 削除確認画面
- 存在しないデータへの404対応
- 登録・編集・削除後のflashメッセージ表示

## 工夫した点

- 支出を遠征に紐づけることで、遠征ごとの合計金額を確認できるようにしました。
- 遠征詳細ページから支出の追加、編集、削除を行った場合、元の遠征詳細ページへ戻るようにしました。
- 支出が紐づいている遠征は削除できないようにし、データの整合性を保つようにしました。
- 金額をカンマ区切りで表示するために、Jinja2のカスタムフィルターを使用しました。
- カテゴリ別・月別の集計にSQLの'GROUP BY'や'SUM'を使用しました。
- 遠征一覧で支出がない場合も'0円'と表示できるように、SQLの'COALESCE'を使用しました。
