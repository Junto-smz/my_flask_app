# Jリーグアウェイ遠征家計簿

##　概要
Jリーグのアウェイ観戦・遠征にかかった費用を記録、管理するためのWebアプリです。
遠征ごとに交通費、宿泊費、チケット代、食費、グッズ代などの支出を登録し、遠征単位・カテゴリ単位・月単位で支出を振り返ることができます。

## 作成背景
Jリーグ観戦では、チケット代だけでなく、交通費、宿泊費、食費、グッズ代など複数の費用が発生します。
そのため、遠征毎にどれくらい費用が掛かったのかを記録し、あとから振り返ることが出来るアプリを作成しました。
このアプリはFlask, SQLite, HTML/CSS, Git/GitHubの学習成果物として作成しています。
FlaskとSQLiteを用いて、Webアプリケーションの基本的なCRUD処理、SQLによる集計、テーブル同士のリレーションを学ぶことを目的に開発しました。

## 工夫した点

###　遠征と支出を紐づけたデータ設計
支出を単体で管理するだけではなく、'expenses'テーブルに'trip_id'を持たせることで、どの遠征にかかった支出なのかを管理できるようにしました。
これにより、遠征詳細ページでその遠征に紐づく支出だけを表示したり、遠征ごとの合計金額を計算できるようにしています。

### SQLによる集計処理
支出金額の集計には、SQLの'SUM' や 'GROUP BY' を使用しました。
カテゴリ別合計、月別合計、遠征毎の合計金額、遠征内のカテゴリ別合計などをSQLで集計することで、登録されたデータを様々な切り口で確認できるようにしました。
また、支出がまだ登録されていない遠征でも "0円" と表示できるように、'COALESCE' を使用しました。

### LEFT JOINを使った一覧表示　
遠征一覧ページでは、'trips' テーブルと 'expenses' テーブルを 'LEFT JOIN' し、遠征ごとの合計金額を表示しています。
'LEFT JOIN' を使うことで支出がまだ登録されていない遠征も一覧に表示できるようにしました。
また、トップページの支出一覧では、支出に紐づく遠征名を表示するために、'expenses'と'trips'を結合しています。

### 操作後の戻り先を考慮した画面遷移
遠征詳細ページから支出の追加、編集、削除を行った場合は、処理後に元の遠征詳細ページへ戻るようにしました。
そのために、URLのクエリパラメータやhidden inputを使って、どの遠征詳細ページから操作されたのかを保持しています。
通常のトップページから操作した場合はトップページへ戻り、遠征詳細ページから操作した場合はその遠征詳細へ戻るように分岐させました。

### 削除前確認とデータ保護
支出や遠征を削除する前に確認画面を表示し、誤作動による削除を防ぐようにしました。
また、支出が紐づいている遠征は削除できないようにし、存在しない遠征を参照する支出が残らないようにしています。

###　入力チェックとエラー対応
支出日、カテゴリ、金額、遠征名、試合日、対戦相手などの必須項目に対して入力チェックを行っています。
金額には数値変換時の例外処理を入れ、数値以外が送信された場合でもアプリが落ちないようにしました。
また、存在しない支出IDや遠征IDにアクセスされた場合は、404ページを表示するようにしています。
